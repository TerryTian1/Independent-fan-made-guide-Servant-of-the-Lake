# 内容素材使用记录

本地站点由项目根目录中已审核的文件生成：

| 根目录素材 | 在站点中的用途 |
|---|---|
| `homepage.json` | 首页 Hero、游戏数据、Start Here、About 和 CTA 文案 |
| `keywords.json` | 19 个最终英文关键词与四大分类 |
| `关键词.md` | 同义词合并、过滤与命名决策 |
| `关键词素材.md` | 24 任务时间线、成就、谜题、隐藏链和事实冲突记录 |
| `favicon_io/` | 浏览器标签、Apple Touch 和 Android 图标 |

## 内容边界

- 竞品页面只用于交叉验证事实和观察信息结构，本站没有复制竞品代码、图片或整段文案。
- `You've Found Him!` 首个时钟线索存在 `3:05` / `4:05` 版本冲突，页面保留冲突说明，不伪造唯一答案。
- 剧情身份、隐藏信件链和结局解释使用折叠剧透区。
